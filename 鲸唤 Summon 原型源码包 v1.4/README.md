# 鲸唤 Summon — 设计系统与交互原型 · 源码包 v1.4

Windows 桌面端轻量 AI 快捷对话工具的**设计规范 + 可交互原型**，单文件 HTML，零依赖、零构建。

## 打开方式

1. 解压本包到任意目录。
2. 双击 `index.html`（或拖入任意现代浏览器：Chrome / Edge / Firefox / Safari 均可）。
3. 无需安装任何依赖、无需启动本地服务器、无外网请求——全部样式、图标（内联 SVG sprite）、脚本都在这一个文件里。

## 可交互清单（原型区，#proto）

- 快捷输入态：Enter 发送 → 自动展开为对话态；Shift+Enter 换行
- 对话态：顶栏新对话 / 历史 / 模型 / 角色 / 更多 / 设置 / 关闭；流式回复（定时器模拟，含光标闪烁）；流式期间发送键变停止键，停止后显示「已停止」
- 右缘跳转刻度：右对齐 8px、当前刻度向左凸出 12px，点击跳到对应提问
- 历史侧栏：240ms 丝滑滑出，支持搜索过滤、进入对话、删除（二次确认）
- 设置页：提供商/模型合并页（获取模型、自定义 Provider）、角色预设（多行 System Prompt、新建/编辑/删除）、快捷键录制（含冲突演示）、外观（字号/主题）、通用（开机启动、检查更新）；保存有成功 Toast 与失败横幅双反馈
- 全局：顶部主题（浅/深/跟随系统）与字号（100/125/150%）切换，对全页实时生效；Esc 逐层收起（浮层 → 抽屉 → 确认框 → 窗口）
- 响应式演示区：360 / 480 / 720 / 900px 四档宽度切换，可与字号、主题三轴组合

## 边界说明

- 本包为**源码重建版**：与此前云端在线演示基于同一份 design.md（v1.4），功能与状态覆盖一致，但代码为独立实现，不是在线部署应用的同一份文件（在线应用的构建产物在隔离环境，源文件无法导出）。
- 不实现 Agent、模型调用、凭据加密、会话持久化等逻辑；窗口阴影为网页展示模拟，真实产品由 OS 窗口管理器提供。
- Figma 源文件（.fig）无法在本环境产出；`index.html` 交付区有 Token → Figma Variables 映射表，可据此在 Figma 复原。
- 图标：Fluent UI System Icons 风格的内联 SVG（本包内为风格一致的重新绘制）。Fluent UI System Icons 由 Microsoft 以 MIT License 发布（商用需随产品附 LICENSE 文本，来源 https://github.com/microsoft/fluentui-system-icons ）；备选 Lucide（ISC License）。
