概览

Windows 桌面端轻量 AI 快捷对话工具：全局快捷键呼出、输入、流式回复、离开。本页为源码版（v1.4），单文件 HTML，可直接本地打开；完整参数见 design.md。

设计关键词 → 参数映射：轻量/克制 → 单一鲸蓝强调色、无渐变无玻璃拟态、阴影仅浮层 ｜ 原生桌面感 → Segoe UI、紧凑控件、细边框 ｜ 低干扰 → 动效 ≤240ms、无装饰元素 ｜ 清晰层级 → 明度与字重表达层级。
修订要点
v1.1气泡仅包裹文字、复制键移出气泡；System Prompt 多行输入；提供商与模型合并＋获取模型＋自定义 Provider；融合滚动条、名称不截断；弹层置顶不裁剪；去重＋历史侧栏；渐变模糊过渡带；初始态去输入框背景；右缘跳转刻度
v1.2修复浅色主题白字：全站文字只引用主题变量，浅字永远绑深底
v1.3刻度条避开滚动条；模糊带下边界贴输入框上沿、越界裁剪
v1.4刻度条右对齐、当前刻度向左凸出、长度减半（8/12px）；全局动效体系（抽屉 240ms、视图 180ms、浮层 160ms）

原型 · 对话状态说明

发送后窗口展开为完整对话：顶栏（新对话 / 历史 / 模型 / 角色 / 设置 / 关闭）、可滚动消息区、透明 composer；流式生成期间发送键变为停止键；底部为渐变高斯模糊过渡带（下边界贴住输入区上沿）。

原型 · 设置页说明

提供商与模型合并为一页（获取模型 → 可用模型 + 上下文配置；自定义 Provider 需填 Base URL / Model ID）；角色描述为多行 System Prompt 输入；含快捷键录制（含冲突演示）、字号、主题、开机启动；保存有成功 Toast 与失败横幅两种反馈。

超长消息

这是一条非常长的用户消息测试文本，用于验证气泡在极端长度下的换行行为：鲸唤是一个 Windows 桌面端的轻量 AI 快捷对话工具，用户通过全局快捷键呼出窗口，输入问题、选择模型和角色，并获得流式回复，它不是浏览器网页、聊天网站或大型 AI 工作台，而是随时呼出、快速使用、低干扰的桌面工具，长文本应当在气泡内正常换行而不是横向撑破布局。
AI 回复同样需要处理超长内容：本条回复验证正文的 overflow-wrap 行为以及阅读列限宽规则，在宽窗下正文不超过 40rem，避免行长失控影响可读性，这行文字比较长，用于触发多行渲染效果以检查行高与间距是否稳定。

边界与待确认

· 本页为源码重建版：与云端在线版基于同一份 design.md（v1.4），功能与状态覆盖一致，但代码为独立实现，非在线部署应用的同一份文件。

· 全部对话内容、模型清单（含上下文配置）、角色、API Key 均为演示数据；不实现 Agent、模型调用、凭据加密与会话逻辑。
