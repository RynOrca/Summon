# 鲸唤 Summon — 设计规范与设计图 v1.0

> Windows 桌面端轻量 AI 快捷对话工具。本文件是 UI 设计师产出的设计定调、Design Token、组件状态矩阵、三大界面线框、响应式规则与交付页结构，作为实现「设计系统 + 交互原型」网页的唯一实现依据。

---

## 0. 设计定调

| 维度 | 决定 |
|---|---|
| 目标用户 | Windows 重度用户 / 开发者 / 知识工作者，需要"随手呼出问一句" |
| 场景/设备 | Windows 10/11 桌面，全局快捷键呼出的小窗，键鼠操作为主，键盘优先 |
| 核心任务 | 呼出 → 输入 → 发送 → 读流式回复 → Esc/关闭离开，全程 ≤ 3 秒上手 |
| 品牌调性 | 轻量、克制、原生桌面感（贴近 Win11 原生控件气质，而非 Web SaaS） |
| 硬约束 | 明暗双主题；窗口可缩放 320–900+px；字号可放大至 125%/150%；WCAG 2.2 AA |

**风格关键词 → 参数翻译**：
- 轻量/克制 → 单一强调色（鲸蓝）、无渐变、无玻璃拟态、阴影极少（仅浮层有）
- 原生桌面感 → Segoe UI 字体、紧凑控件（28–32px 高）、细边框（1px）、系统级焦点环
- 紧凑但不拥挤 → 4px 间距栅格、消息区 16px 内边距、行高 1.55 留呼吸感
- 清晰层级 → 层级只用「色彩明度 + 字重」表达，不用阴影堆叠
- 低干扰 → 弹出动画 ≤160ms、无边框装饰、无营销元素

**明确避免**（用户点名）：SaaS 仪表盘感、大面积渐变、玻璃拟态、卡片堆叠、巨大标题、网页导航栏、营销落地页风、过度圆角、装饰性图标、固定尺寸布局。

## 1. Design Tokens（实现为 CSS 自定义属性，双主题切换）

### 1.1 色彩

```css
:root, [data-theme="light"] {
  --bg: #FFFFFF;            /* 窗口背景 */
  --surface: #F6F7F8;       /* 输入框、次级面板 */
  --surface-2: #EDEFF2;     /* 选中态底、悬停底 */
  --border: #D9DDE3;        /* 1px 常规边框 */
  --border-strong: #B8BEC9; /* 悬停边框 */
  --text-primary: #17191D;  /* 正文 */
  --text-secondary: #565D68;/* 次级文字，白底对比 ≥5.4:1 */
  --text-disabled: #9AA1AC; /* 禁用文字 */
  --accent: #2E6BE6;        /* 鲸蓝：链接/主按钮文字 */
  --accent-hover: #1F56C9;
  --accent-pressed: #17439C;
  --accent-fill: #2E6BE6;   /* 主按钮/发送键填充 */
  --on-accent: #FFFFFF;
  --accent-subtle: #E8EFFC; /* 选中模型/角色 chip 的底色 */
  --success: #1E8E4E;  --success-bg: #E6F6EC;
  --warning: #A85A00;  --warning-bg: #FBF1E2;
  --error: #C62F1F;    --error-bg: #FBE9E7;
  --skeleton-a: #EDEFF2; --skeleton-b: #F8F9FA; /* 加载占位 */
}
[data-theme="dark"] {
  --bg: #191B1F;
  --surface: #212429;
  --surface-2: #2A2E35;
  --border: #383D45;
  --border-strong: #4A505B;
  --text-primary: #ECEEF1;
  --text-secondary: #A6ADBA;
  --text-disabled: #646B77;
  --accent: #6B93F0;        /* 暗色下链接/强调文字 */
  --accent-hover: #82A4F5;
  --accent-pressed: #5479D6;
  --accent-fill: #3A63D6;   /* 暗色下主按钮填充，白字对比 ≥4.6:1 */
  --on-accent: #FFFFFF;
  --accent-subtle: #26314A;
  --success: #4CBF7E;  --success-bg: #1B2E24;
  --warning: #E0A03C;  --warning-bg: #33280F;
  --error: #EF6A5A;    --error-bg: #3A1F1B;
  --skeleton-a: #23262B; --skeleton-b: #2C3037;
}
```

- 流式回复光标：2px 宽、1em 高的 accent 色竖线，1s 呼吸闪烁。
- 焦点环：`2px solid --accent`，`outline-offset: 2px`，仅 `:focus-visible` 显示。
- 消息气泡：用户消息 `--accent-fill` 底 + `--on-accent` 字；AI 回复无气泡底、仅正文（更接近"阅读"而非"聊天软件"）。

### 1.2 字体

```css
--font-ui: "Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", system-ui, sans-serif;
--font-code: "Cascadia Code", Consolas, ui-monospace, monospace;
```

| Token | 值 | 用途 |
|---|---|---|
| --fs-title | 1.0625rem (17px) / 600 | 空态提示标题 |
| --fs-body | 0.875rem (14px) / 400 | 正文、消息、输入框 |
| --fs-secondary | 0.75rem (12px) / 400 | chip、工具栏、提示 |
| --fs-caption | 0.6875rem (11px) / 400 | 时间戳、辅助说明 |
| --fs-display | 1.25rem (20px) / 600 | 仅设计系统页标题，产品界面内禁用巨大标题 |

所有字号用 **rem**；字号缩放档位通过根元素实现：100% → `html{font-size:16px}`，125% → 20px，150% → 24px。行高：正文 1.55，UI 文字 1.3。

### 1.3 间距 / 圆角 / 阴影 / 动效

| Token | 值 |
|---|---|
| --sp-1 / 2 / 3 / 4 / 5 / 6 / 8 | 4 / 8 / 12 / 16 / 20 / 24 / 32 px |
| --r-control | 6px（按钮、chip、输入框） |
| --r-card | 8px（用户消息气泡、浮层面板） |
| --r-window | 10px（桌面窗口外框，Windows 11 圆角） |
| --r-badge | 4px（徽标、代码块标签） |
| --shadow-window | 0 24px 48px rgba(0,0,0,.18)（仅网页展示用的窗口框） |
| --shadow-pop | 0 8px 24px rgba(0,0,0,.14)（下拉/Toast/对话框浮层） |
| --shadow-card | none（卡片一律用 1px 边框，不用阴影） |
| --dur-fast | 120ms ease-out（hover/press） |
| --dur-expand | 160ms ease-out（空态 → 对话展开） |
| --caret-blink | 1s steps(2) infinite（流式光标） |

## 2. 组件状态矩阵（每个组件必须展出全部状态）

### 2.1 按钮 Button
- 变体：primary（accent-fill 底）、secondary（surface 底 + 1px border）、ghost（无边框）、danger（error 色）
- 高度 32px（常规）/ 28px（紧凑，顶栏与窄窗用）；内边距 0 12px；最小宽度无（文字按钮）
- 状态：default / hover（加深一档 + 边框加深）/ pressed（再加深 + `transform: translateY(0.5px)`）/ disabled（文字 --text-disabled，填充 --surface-2，cursor: not-allowed）/ focus-visible（2px 焦点环）/ loading（图标旋转，宽度锁定防跳动）

### 2.2 图标按钮 IconButton（顶栏与操作区）
- 28×28px 命中区，图标 16px；状态：default(secondary 图标) / hover(surface-2 圆形底) / pressed / disabled / focus-visible / loading（旋转环）
- 关闭按钮 hover 时变 error 色（桌面惯例）

### 2.3 输入框 Input / 多行输入 Textarea
- 单行：高 32px，border 1px，圆角 6px，聚焦时 border 变 accent + 焦点环
- 状态：default / hover(border-strong) / focus / disabled / error（border 变 error + 12px 错误文字在下方）
- 多行（对话输入）：auto-grow，min-height 40px、max-height 160px，超出内滚动；placeholder 用 --text-secondary

### 2.4 下拉选择 Select（模型 / 角色）
- 触发器 = chip 样式（surface 底、6px 圆角、12px 字号 + 16px 图标 + 12px 展开箭头）
- 状态：default / hover / open（accent-subtle 底 + accent 边框）/ disabled / focus-visible
- 浮层：max-height 240px 内滚动，选中项前有 12px 勾选标记；项目文字过长 → 单行省略（max-width 200px + ellipsis），tooltip 显示全名

### 2.5 消息 Message
- 用户消息：右对齐，accent-fill 底圆角 8px，max-width 85%（窄窗 92%），文字 14px/1.55
- AI 回复：左对齐，无底色，顶部 12px 角色名（caption、secondary），支持代码块（--font-code，surface 底，badge 圆角 4px，带复制按钮）
- 状态：流式中（尾部光标闪烁 + 底部停止按钮）/ 完成 / 生成失败（消息底部 error 色重试链接）/ 内容过长（限宽换行，代码块横向滚动，不撑破布局）
- 操作：hover 消息 → 浮现复制/重试 16px 图标按钮（secondary 色）

### 2.6 停止生成按钮 StopButton
- 出现在输入框右下原发送键位置：28px 方形 secondary 底，内部 12px 实心方块图标
- 状态：default / hover（error 色边框）/ pressed / 流式中持续显示

### 2.7 开关 Toggle / 复选 Checkbox
- Toggle 32×18px，开 = accent-fill，关 = surface-2 + border；状态含 disabled、focus-visible
- Checkbox 16px 常规 1px 边框，选中 accent-fill + 白勾

### 2.8 快捷键录制 HotkeyRecorder
- 触发器显示当前快捷键（kbd 样式：surface 底、4px 圆角、12px 字号、code 字体）
- 点击进入「录制中」：边框 accent、显示"按下新组合键…"、右侧取消图标；Esc 取消
- 冲突态：录制结果下方 warning 色文字"与系统/其他应用快捷键冲突"，kbd 变 warning 边框

### 2.9 Toast 通知
- 底部居中浮出（窗口内），圆角 8px + --shadow-pop，4s 自动消失，hover 暂停留
- 变体：success（success 色图标）/ error（error 色图标）/ info（accent）；文字 12px

### 2.10 对话确认框 ConfirmModal
- 窗口内居中、宽 min(320px, 90vw)，--shadow-pop，8px 圆角
- 内容：warning 图标 + 标题（14px/600）+ 说明（12px）+ 右对齐按钮组（secondary 取消 + danger 确认）
- 遮罩 rgba(0,0,0,.32)；Esc = 取消；用于「删除角色」「清除密钥」二次确认

### 2.11 Toast/骨架屏 Skeleton
- Agent 启动中：消息区顶部 12px 状态行（旋转 spinner 16px + "连接模型…"）
- 连接失败/凭据缺失/模型不可用：消息区居中错误块（图标 + 标题 + 说明 + 操作按钮），非模态、不阻断输入

### 2.12 键盘交互约定（产品级）
- 全局：Enter 发送、Shift+Enter 换行、Esc 关闭窗口、Ctrl+N 新对话、Ctrl+, 打开设置
- 网页原型中以上均需可用（Esc 在原型容器内为收起演示面板，需在说明中标注差异）

## 3. 界面线框（三大界面）

### 3.1 初始快捷输入态（呼出即见，默认 480×520）

```
┌──────────────────────────────┐ 40px 顶栏（此态隐藏或极弱化）
│                              │
│                              │   ↑ 大量留白，视觉只服务一件事
│   ┌────────────────────────┐ │
│   │ 问点什么…               │ │   ← 40px 高输入框，光标聚焦即在此
│   │ (Enter 发送·Shift+Enter换行) │ │     placeholder 12px 附行
│   └────────────────────────┘ │
│      [🤖 GPT-4o ▾][🎭 翻译官 ▾] │   ← 模型/角色 chip，secondary 弱化
│                              │      距输入框 8px，居中
│                              │
└──────────────────────────────┘
```
- 无欢迎语、无功能介绍、无空白气泡。焦点自动落输入框。
- chip 为「可见但弱化」：12px secondary 文字 + 图标，hover 才出现 surface-2 底。

### 3.2 对话态（发送后 160ms 展开动画）

```
┌──────────────────────────────┐
│ [＋新对话][GPT-4o ▾][翻译官 ▾]  │ [⚙][✕]  ← 顶栏 44px：新对话/模型/角色 | 设置/关闭
├──────────────────────────────┤
│                              │
│           ┌──────────────┐ │
│           │ 用户消息(右对齐) │ │   ← 消息区：可滚动，16px 内边距
│  角色名    │                │ │     窗口 <560px 时阅读列限宽 640px 居中
│  AI 流式回复▌(光标闪烁)      │ │     滚动条 8px 细样式，hover 加深
│           └──────────────┘ │
├──────────────────────────────┤
│ ┌────────────────────────┐ │
│ │ 多行输入…  [⏹停止] [➤发送] │ │   ← 底部固定 composer：输入时
│ └────────────────────────┘ │     auto-grow，max 160px；流式期间
└──────────────────────────────┘     发送键变为停止键，输入可继续打字
```
- **底部不遮挡消息**：消息区 `padding-bottom` 随 composer 实际高度联动（JS 同步）。
- 流式中：消息尾部光标闪烁 + 顶部无变化（不做大面积遮罩）；停止后光标消失。

### 3.3 设置态

```
┌──────────────────────────────┐
│ [← 返回] 设置                 │   ← 44px 顶栏
├───────────┬──────────────────┤
│ 提供商     │ (当前分区内容)     │
│ 模型       │                  │
│ 角色预设   │   ≥560px：       │
│ 快捷键     │   左侧 160px 导航 │
│ 外观       │   + 右侧内容滚动  │
│ 通用       │                  │
├───────────┴──────────────────┤
│            [保存]  状态提示     │   ← <560px：导航折叠为顶部横向 tab
└──────────────────────────────┘
```
分区内容：
1. **提供商**：Provider 下拉 + API Key 密码框（右侧「显示/清除」；清除需确认框）+「测试连接」按钮（loading/成功/失败三态）
2. **模型**：启用列表（Checkbox 多选）+ 默认模型 Select + 长模型名省略示例
3. **角色预设**：列表（名称 + 描述摘要 + 编辑/删除图标按钮；删除弹确认框）+ 新建按钮
4. **快捷键**：呼出窗口热键录制（含冲突演示）+ 每条操作快捷键只读展示
5. **外观**：字体大小（100/125/150% 分段控件，改动即时生效）+ 主题（浅色/深色/跟随系统 三选一）
6. **通用**：开机启动 Toggle + 检查更新按钮

保存反馈：成功 → Toast「设置已保存」；失败 → 表单区顶部 error 横条 + 保留用户输入；凭据保存成功 → Toast「密钥已加密保存」。

## 4. 响应式与可缩放规则

| 档位 | 宽度 | 规则 |
|---|---|---|
| 最窄 | 320–360px | 顶栏仅图标（新对话/模型/角色合入一个「…」溢出菜单，设置/关闭保留）；chip 只显示图标+短名（GPT-4o→4o）；消息 max-width 92%；composer 图标按钮 24px；设置导航折叠为顶部横向 tab；全部触摸目标仍 ≥24px |
| 常规 | 480×520 | 默认形态，按线框 3.1/3.2 |
| 宽 | 720–900px | 消息区阅读列 max-width 640px 居中；chip 展开显示全名；设置恢复左导航；顶栏按钮全部显示文字标签 |
| 更宽 | >900px | 同宽窗规则，阅读列不再加宽（保护行长 ≤ 75 字符/行） |

**字号缩放（与宽度正交）**：100%/125%/150% 三档，全部尺寸 rem 化后自动联动；150% + 320px 组合下：顶栏允许滚动省略、消息不截断、按钮仍可点。原型必须内置「宽度档位（360/480/720/900）× 字号（100/125/150%）× 主题（浅/深）」三组切换器实时演示，包含**窄窗 + 大字体**组合态。
**禁止固定像素布局**：布局全部 flex/grid + min/max 约束；窗口最小尺寸 320×400。

## 5. 必须覆盖的状态全景（原型需可逐一切换演示）

| 状态 | 展示位置 |
|---|---|
| 空白 | 初始输入态原型 |

## 7. 交付网页的结构（单页应用，左侧固定导航）

1. **概览**：产品定位一句话、设计关键词→参数映射表、本页使用说明
2. **Design Tokens**：明暗双主题色板（可切换）、字体阶梯、间距/圆角/阴影/动效表——全部数值即实现所用 CSS 变量
3. **组件状态库**：§2 矩阵逐组件展架，每个状态实物陈列并标注 Token 来源
4. **原型 · 快捷输入**：窗口框内可交互（输入 → Enter → 跳转对话态）
5. **原型 · 对话**：流式模拟、停止/重试、快捷键提示
6. **原型 · 设置**：六分区完整表单 + 保存/冲突/确认演示
7. **状态全景**：§5 清单逐项小窗陈列，可点击切换
8. **响应式演示**：宽度 360/480/720/900 × 字号 100/125/150% × 主题 三轴切换器 + 对话原型实时联动（含窄窗+大字体组合）

## 10. v1.2 缺陷修复：浅色主题下文字为白色（用户反馈截图 bug-light-theme.png）

**现象**：切到浅色主题后，AI 回复正文等部分文字仍为白色/浅灰，在白底上不可读。

**根因要求**：全站配色**只允许引用 CSS 自定义属性**（--text-primary / --text-secondary / --bg / --surface / --border…），**禁止任何写死的白色/浅灰文字色**（如 #FFF、#FFFFFF、#ECEEF1、#E8EAED、rgba(255,255,255,…) 一律不得出现在元素样式中；纯白仅允许作为 --on-accent 出现在蓝色主按钮/用户气泡内）。若确需固定色值（如深色气泡上的白字），必须在该元素上显式锁定深色背景，即"浅字永远绑深底"。

**修复清单**：
1. 全局审计浅色主题下所有界面文字色，确保正文 = --text-primary（浅色 #17191D / 深色 #ECEEF1 随主题切换），次级 = --text-secondary；
2. 重点排查：AI 回复正文、代码块文字、chip/下拉/按钮文字、消息 hover 操作按钮、设置表单、历史侧栏、状态全景区各演示块；
3. 自定义 Provider、「获取模型」列表、历史抽屉等 v1.1 新增区域一并排查；
4. 修复后浅色主题所有文字在白底对比度 ≥4.5:1，深色主题文字在暗底同样达标；受影响状态全景区需同步修正。

## 11. v1.3 修订（用户 2 条反馈；截图 fb2-01 / fb2-02）

### 11.1 右缘跳转刻度条：避开滚动条 + 当前刻度向右凸出
- **位置**：刻度列整体位于滚动条**左侧**，与滚动条区域零重合——消息区右缘先为滚动条预留 8px 命中区，刻度列紧贴其左（右偏移 = 滚动条区宽 + 4px 间隙）；滚动条显示/隐藏切换时刻度位置保持稳定不跳动。
- **当前刻度凸出**：默认每条刻度宽 16px、右端基线对齐；**当前高亮（当前视口所邻/最近点击）的刻度在右端向右凸出 1/4 刻度长度**（即宽度 16px → 20px，右端超出基线 4px），形成"选中凸舌"形态；点击其他刻度后高亮与凸出随之移动，过渡 120ms。
- 其余规则（一问一刻度、点击平滑定位、流式中最末高亮、hover 命中区放大）不变。

### 11.2 渐变模糊过渡带：严格贴住输入框上沿、越界部分不可见
- **缺陷**：模糊带向下延伸越界，超出输入框范围仍然可见（见 fb2-02）。
- **修复规则**：
  1. 模糊带**下边界必须严格贴住输入区（composer）的上边界**，二者零间隙、零越界——模糊带作为消息滚动容器的绝对定位子层，`bottom: 0` 且容器本身以 composer 顶边为底，不允许用固定高度另算；
  2. 越界部分一律**隐藏**：模糊带所在容器 `overflow: hidden`，backdrop-filter 的作用范围不得延伸到输入区或窗口边缘之外；如需输入区遮挡则输入区背景置于模糊带之上（z-index 更高）；
  3. 模糊带高度仍为 64px，从消息区底部向上渐隐（blur 8px → 0、渐变透明 → --bg）；
  4. 该规则适用于对话态、状态全景各演示块、响应式演示区中的全部对话实例；窗口任意缩放、字号缩放、深浅主题切换后边界依然贴合。

## 12. v1.4 修订（用户 2 条反馈；截图 fb3-01）——以此覆盖 §11.1 中与之冲突的描述

### 12.1 跳转刻度条：右对齐 + 当前刻度向左凸出 + 长度减半
- **默认刻度长度减半**：由 16px 改为 **8px** 宽（2px 高、4px 圆角、间距 4px），hover 命中区 12px 宽不变。
- **右对齐**：全部刻度**右端统一对齐**在同一右基线（滚动条左侧 4px 间隙处），滚动条显隐时位置依然稳定。
- **当前刻度向左凸出**：当前高亮（当前视口所邻/最近点击）的刻度**向左延伸**，宽度 8px → 12px（凸出 4px），右端仍贴基线——即"凸舌"朝左；点击切换后凸出随高亮移动，120ms 过渡。
- 其余规则（一问一刻度、点击平滑定位、流式中最末高亮、避开滚动条）不变。

### 12.2 全局过渡动画体系（页面切换丝滑化）
新增动效 Token：
```
--dur-fast: 120ms ease-out        /* hover/press/刻度切换 */
--dur-expand: 160ms ease-out      /* 空态→对话展开 */
--dur-drawer: 240ms cubic-bezier(0.2, 0, 0, 1)  /* 抽屉/浮层滑入 */
--dur-view: 180ms ease-out        /* 视图/页面切换 */
--ease-smooth: cubic-bezier(0.2, 0, 0, 1)
```
逐场景要求：
1. **历史侧栏**：点击历史按钮 → 抽屉以 240ms 从左侧滑入（--ease-smooth），遮罩同步淡入（180ms）；关闭时反向滑出；列表项错峰 fade-in-up（每项延迟 30ms，120ms 过渡）。
2. **主内容区视图切换**（快捷输入 ↔ 对话 ↔ 设置等）：容器间 180ms 淡入 + 4px 上移过渡，不整页跳变；初始态 → 对话态沿用 160ms 展开动画。
3. **浮层**（模型/角色下拉、确认框、Toast）：160ms scale(0.96→1) + fade 弹入；Toast 底部上浮 8px 进入。
4. **主题切换**：颜色过渡 200ms（`transition: background-color/color/border-color .2s`），无闪烁。
5. **状态全景各演示卡**：切换状态时同样应用对应动效，与主原型一致。
6. **无障碍**：`@media (prefers-reduced-motion: reduce)` 下全部动画降为 opacity 淡入或直接切换，不做位移缩放。
7. **性能**：仅用 transform/opacity 驱动，禁用会触发重排的属性动画；动效不得造成任何布局跳动。
