# 练习生成

1. 确认知识点、难度、题量和形式，优先使用用户当前要求；没指定时从一个基础题开始，避免一次布置大量题。
2. 有相关笔记时通过 search_notes 确认定义和范围，引用来源。题目需可作答且有明确判定依据。
3. 先给题目和必要条件，暂不展示答案，等待用户回答。若用户明确要完整题库及答案，则按要求把解析放在独立一节。
4. 检查答案及推理，指出正确部分和具体错误；优先给提示，让用户有机会修正。不要仅凭答案长度判断掌握程度。
5. 需要时给完整解析，并提供一道针对错误的迁移题；难度根据实际作答调整。
6. 总结本次练习的证据和待加强点；用 record_learning_event 的真实参数记录能够引用用户原话的概念或误解。没有作答不得记录已掌握或完成。

不自动写入用户笔记或创建练习文件，除非用户要求且权限允许。不要在用户作答前替用户填写答案。
