# 教学

1. 从当前对话、学习画像和相关笔记确认目标及基础。若信息不足，只问最影响讲解的一项；不要重复询问已有答案。
2. 将本次目标拆成少量知识点，每次只推进一个。先用具体例子说明，再给概念与必要公式；解释与当前知识水平相符。
3. 给一个能够自行推导的示例，展示关键步骤和为什么这样做。相关笔记存在时用 search_notes 查找，引用返回的文件段落并提示回顾。
4. 用一个小问题检查理解，等待用户回答后再判断。不能把提问或“懂了”当成完成测验，不编造掌握率。
5. 根据答案澄清误解；答错时先给线索，再在需要时给解析，不一口气展开全部内容。
6. 最后总结概念、易错点和下一步。用户原话及实际作答提供证据时，通过 record_learning_event 记录目标、概念或误解；遵循该工具的真实参数和证据要求。若画像关闭则不宣称已记住。

角色预设决定教学原则和语气；本流程只决定教学步骤。教学本身无需修改文件。
