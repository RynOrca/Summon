通用

窗口与快捷键

开机自启

登录 Windows 后启动到托盘，随时用快捷键呼出。

呼出快捷键

点击后按下组合键。Esc 取消，快捷键冲突会提示。

轻量悬浮窗

关闭对话窗口后驻留托盘；设置使用独立窗口。滚动区域保留滚动操作，隐藏滚动条。

已配置的提供商

新增提供商

自定义

本地、另一台电脑和云端接口使用同一配置流程。Key 由当前 Windows 用户的凭据保护加密保存。

接口未提供信息？手动补充

标准模型列表可能只返回 ID。未知能力不会被猜测；可按服务端配置补充。

Agent 整理，按需召回

Agent 在对话中记住明确的偏好和学习信息，回复结束后在后台整理。新的提问会取消尚未完成的整理任务。你可以直接在对话中要求纠正记忆。

学习者画像 · L1

保存明确的学习背景与稳定偏好，每轮注入精简画像。

知识库 · L2

Agent 归档值得复用的知识笔记，以本地文本检索召回。

跨对话记忆 · L3

检索相关历史片段，保留来源；不额外部署向量数据库。
