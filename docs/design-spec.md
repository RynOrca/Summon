**语义别名与同值关系**（源文档未用 "alias" 措辞，下列为可验证的同值/角色关系）
- `--accent-fill` ≈ `--accent`：**仅浅色同值** `#2E6BE6`；暗色分别为 `#3A63D6` / `#6B93F0`（填充更暗以保白字 ≥4.6:1）——**不可互相替换**。
- `--surface-2` = `--skeleton-a`：浅色同为 `#EDEFF2`；暗色不同（`#2A2E35` / `#23262B`）。
- `--accent-subtle` = 「选中 chip 底」，未声明等于任何 primitive；`--on-accent` 恒为 `#FFFFFF`（两主题同值，纯白唯一合法用途）；`--shadow-card: none` 即「卡片不用阴影」。

**其他具名规格（非 Token，实现必需）**

| 项 | 值 | 出处 |
|---|---|---|

| **z-index** | **未规定**（源文档无 z-index Token）。`[proto]` 参考值：ticks 4 / fade-band 2 / composer 3 / popmenu 400 / 历史遮罩 450 / 抽屉 460 / ConfirmModal 遮罩 500 / Toast 600 | — |

## 2. 排版阶梯

| Token | 值 | 字重 | 行高 | 用途 |
|---|---|---|---|---|
| `--fs-title` | 1.0625rem (17px) | 600 | 未规定（按 UI 文字规则 → 1.3） | 空态提示标题 |
| `--fs-body` | 0.875rem (14px) | 400 | **1.55** | 正文、消息、输入框、多行输入 |
| `--fs-secondary` | 0.75rem (12px) | 400 | 未规定（→ 1.3） | chip、工具栏、提示、Toast 文字、下拉项 |
| `--fs-caption` | 0.6875rem (11px) | 400 | 未规定（→ 1.3） | 时间戳、辅助说明、角色名、代码块语言标签 |
| `--fs-display` | 1.25rem (20px) | 600 | 未规定 | **仅设计系统页标题**；产品界面内禁用巨大标题 |

- 行高规则原文：「正文 1.55，UI 文字 1.3」→ 正文 = `--fs-body`（1.55），其余为 UI 文字（1.3）。⚠️ title/caption 的归类是按此规则推断，源文档未逐项点名。
- 全部字号用 **rem**；缩放只通过根元素 `font-size` 实现（§1.2、§7）。
- 字体族：全局 `--font-ui`；`--font-code` 用于代码块与快捷键 `kbd`。
- 其他字号未 Token 化：设置分区标题等**未规定**（`[proto]` 13px，非规范）。

## 3. 布局结构（线框）

### 3.0 窗口框（所有态）
- `--r-window: 10px` 圆角外框 + 1px 边框 + `--shadow-window`（网页展示模拟；真实产品阴影由 OS 窗口管理器提供，§8）。
- title bar 显示「**鲸唤 Summon**」+ 最小化/关闭**装饰钮**（§7）；高度**未规定**（`[proto]` 32px）。
- 可缩放 **320–900+px**；窗口最小尺寸 **320×400**；**禁用固定像素布局**（全 flex/grid + min/max 约束，§4）。

### 3.1 初始快捷输入态（默认 480×520；§3.1 + §9.8）
```
窗口
├─ 顶栏 40px（此态「隐藏或极弱化」）
└─ 纵向居中区（大量留白，视觉只服务一件事）
   ├─ 输入框：40px 高，聚焦即在此
   │  ├─ 无边框、无底色、透明、无 surface 填充（§9.8）
   │  ├─ 只保留 placeholder「问点什么…」+ 闪烁光标（光标即输入位置）
   │  ├─ focus 无任何框体描边变化；至多一条极弱 --border 下划线（可选）
   │  └─ 附行提示「Enter 发送 · Shift+Enter 换行」，12px
   └─ 模型 / 角色 chip 行：距输入框 8px，居中，可 wrap
      └─ chip = 12px secondary 文字 + 图标，「可见但弱化」，hover 才出现 --surface-2 底
```
- 无欢迎语、无功能介绍、无空白气泡；**焦点自动落输入框**。

### 3.2 对话态（发送后 160ms 展开动画；§3.2 + §9.1/§9.7/§9.9/§12.1）
```
窗口
├─ 顶栏 44px（顺序固定）
│  ├─ 左组：[＋ 新对话] [🕐 历史] [模型 chip ▾] [角色 chip ▾]
│  └─ 右组：[⋯ 更多] [⚙ 设置] [✕ 关闭]        ← ⋯ 菜单不得含模型/角色重复项（§9.6）；关闭 hover 变 --error
├─ 消息区（flex:1，可滚动，16px 内边距）
│  ├─ 用户消息：右对齐；气泡 inline-block 只包裹文字，max-width 85%（窄窗 92%）
│  │  ├─ 气泡：--accent-fill 底 / --on-accent 字、圆角 8px、padding 8px 12px、14px/1.55、超长正常换行
│  │  └─ 操作键在**气泡外左下角**（hover 该消息浮现，24px ghost 图标按钮，--text-secondary，间距 --sp-1）
│  ├─ AI 回复：左对齐、无底色；顶部角色名（caption、secondary）；正文 14px；支持代码块
│  │  └─ 代码块：--font-code、--surface 底、标签圆角 4px（--r-badge）、带复制按钮；横向滚动不撑破布局
│  ├─ 右缘刻度列（§12.1；垂直居中，见 §5.4）
│  └─ 底部渐变模糊过渡带 64px（§9.7/§11.2；见 §5.5）
└─ composer（底部固定，**无分隔线**，背景透明、置于模糊带之上）
   ├─ 多行 textarea：auto-grow，min-height 40px，max-height 160px，超出内滚动，placeholder --text-secondary
   ├─ 发送键：输入框右下，28px 方形（--accent-fill）；流式期间**变为停止键**（28px 方形 secondary 底 + 12px 实心方块图标）
   └─ 提示行「Enter 发送 · Shift+Enter 换行」
```
- **底部不遮挡消息**：消息区 `padding-bottom` 随 composer 实际高度联动（**JS 同步**，§3.2）。
- 流式中：消息尾部光标闪烁 + 顶部无变化（**不做大面积遮罩**）；停止后光标消失。
- 「窗口 <560px 时阅读列限宽 640px 居中」为源文档原文，语义自相矛盾 ⚠️；§4 等效规则为「720–900px：阅读列 max-width 640px 居中；>900px 不再加宽（行长 ≤ 75 字符/行）」。

### 3.3 设置态（§3.3 + §9.3）
```
窗口
├─ 顶栏 44px：[← 返回] 设置
├─ 主体：≥560px = 左导航 160px + 右侧内容区（独立滚动）；<560px = 导航折叠为顶部横向 tab
└─ 底部保存条：[保存] + 状态提示
```
导航分区（§9.3 合并后由 6 → **5** 个）：`提供商与模型` / `角色预设` / `快捷键` / `外观` / `通用`。
1. **提供商与模型**（§9.3 合并）：Provider 下拉 → API Key 密码框（右侧「显示/清除」；**清除需确认框**）→「测试连接」（loading / 成功 / 失败三态）→「**获取模型**」（loading：旋转 + 「获取中…」→ 成功拉取可用模型列表 + 每项**上下文窗口配置信息**作副标题 → 可勾选列表，勾选即启用；失败：error 行 + 重试）。Provider 含「**自定义**」：展开必填 **Base URL、API Key、Model ID** + 可选「上下文窗口大小、温度参数等」。默认模型从已获取/已启用列表中选择。
2. **角色预设**：列表（名称 + 描述摘要 + 编辑/删除图标按钮；**删除弹确认框**）+ 新建按钮；编辑态描述字段为主体（占满可用宽度）；描述为**多行 System Prompt** textarea（min 96px / auto-grow max 240px，§9.2），列表摘要仍可单行省略。
3. **快捷键**：呼出窗口热键录制（含冲突演示）+ 每条操作快捷键只读展示。
4. **外观**：字体大小（100 / 125 / 150% 分段控件，**改动即时生效**）+ 主题（浅色 / 深色 / 跟随系统 三选一）。
5. **通用**：开机启动 Toggle + 检查更新按钮。

保存反馈：成功 → Toast「设置已保存」；失败 → **表单区顶部 error 横条** + 保留用户输入；凭据保存成功 → Toast「密钥已加密保存」。

### 3.4 历史侧栏（覆盖式抽屉；§9.6 + §12.2）
- 遮罩 `rgba(0,0,0,.32)`（淡入 180ms）；抽屉宽 `min(280px, 80vw)`，从左侧滑出。
- 内容顺序：搜索框 → 历史对话列表（标题 / 时间 / 摘要）；支持点击进入该对话、删除（**二次确认框**）、hover 高亮、当前对话标记。
- 滑入时长：§9.6 写 160ms ease-out，**§12.2 覆写为 240ms + `--ease-smooth`** → 以 §12.2 为准；列表项错峰 fade-in-up：**每项延迟 30ms、120ms 过渡**。
- 满足明暗主题、字号缩放、窄窗自适应；点击遮罩或 Esc 关闭。

### 3.5 浮层与状态块
| 浮层 | 结构 | 定位 / 尺寸 |
|---|---|---|
| Select 下拉（模型/角色） | 列表项：名称 + 副标题；选中项前 12px 勾选标记 | **fixed 浮层**（overflow 不裁剪），允许越出窗口框；`--shadow-pop`；点外/Esc 关闭；最大高度 = 视口可用高度（§9.5）⚠️ 与 §2.4「max-height 240px」冲突 |
| ConfirmModal | warning 图标 + 标题 14px/600 + 说明 12px + 右对齐按钮组（secondary 取消 + danger 确认） | 窗口内居中，宽 `min(320px, 90vw)`，`--shadow-pop`，8px 圆角；遮罩 `rgba(0,0,0,.32)`；Esc = 取消 |
| Toast | success（success 图标）/ error（error 图标）/ info（accent）；文字 12px | 窗口内**底部居中**，圆角 8px + `--shadow-pop`，4s 自动消失，**hover 暂停留**；进入：底部上浮 8px + fade，160ms |
| Agent 启动中 | 消息区**顶部** 12px 状态行：旋转 spinner + 「连接模型…」 | 非模态 |
| 连接失败 / 凭据缺失 / 模型不可用 | 消息区**居中错误块**：图标 + 标题 + 说明 + 操作按钮 | **非模态、不阻断输入** |

## 5. 交互规则

### 5.1 键盘
| 键 | 行为 |
|---|---|
| `Enter` | 发送 |
| `Shift+Enter` | 换行 |
| `Esc` | 关闭窗口；**分层**：浮层 → 历史抽屉 → 确认框 → 收起窗口；录制中 = 取消录制；确认框 = 取消 |
| `Ctrl+N` | 新对话 |
| `Ctrl+,` | 打开设置 |
| 原型差异 | 网页原型中 Esc 在原型容器内为**收起演示面板**，需在说明中标注与产品的差异（§2.12） |

### 5.2 发送 → 流式 → 停止
- 发送 → 用户消息上屏（<300ms 内，spinner 12px ⚠️/16px）→ Agent 启动状态行 → 文字逐字上屏 + 尾部 2px 光标闪烁 → **发送键就地变为停止键** → 点击停止：光标消失、消息尾部出现「已停止」caption。
- 流式期间**输入可继续打字**；顶部无任何变化（不做大面积遮罩）。
- 模型不可用 → 消息内嵌 error 行「该模型当前不可用，请切换模型」。

### 5.3 抽屉、确认与反馈
- 历史抽屉：点历史按钮 → 240ms 左侧滑入（`--ease-smooth`），遮罩淡入 180ms；关闭反向滑出；点遮罩或 Esc 关闭。
- 删除（角色 / 历史对话 / 清除密钥）一律走 **ConfirmModal** 二次确认；Esc = 取消。
- Toast 三变体，4s 自动消失，hover 暂停留；表单失败 = 表单区**顶部 error 横条** + **保留用户输入**（非 Toast 替代）；连接失败 / 凭据缺失 / 模型不可用 = 消息区居中错误块，**非模态、不阻断输入**。

### 5.4 右缘跳转刻度条（**以 §12.1 为准**）
| 属性 | 值 |
|---|---|
| 对应关系 | 每个**用户提问**一条刻度（一问一刻度） |
| 默认尺寸 | 宽 **8px** × 高 **2px**，圆角 **4px**，间距 **4px**（§9.9 的 16×2px / 间距 6px 已废止） |
| 对齐与位置 | 全部刻度**右端统一对齐同一右基线**（位于滚动条左侧 **4px** 间隙处）；消息区右缘内侧、**垂直居中**；整体在滚动条**左侧**、与其零重合；滚动条显隐时位置稳定不跳动 |
| 右偏移 | §11.1 公式 = 滚动条命中区宽（8px）+ 4px 间隙 = **12px**（规范给公式未给数字；`[proto]` 12px，<400px 时 9px） |
| 颜色 | 非当前刻度 `--border-strong`；当前视口所邻的刻度（及最底端）高亮 `--accent` |
| 当前刻度凸出 | **向左**延伸：8px → **12px**（凸出 4px），右端仍贴基线；随高亮移动，过渡 **120ms**（§11.1 的「向右凸出 16→20px」已废止） |
| 点击 / 流式 / hover | 点击 = 平滑滚动定位到对应提问；流式中底端刻度持续高亮；hover 命中区放大至 **12px** 宽 |
| 过渡 | `width 120ms` + `background-color 120ms`（= `--dur-fast`） |

### 5.5 渐变模糊过渡带（§9.7 + §11.2）
- **无 1px 分隔线**（删除消息区与输入区之间的分隔线）。
- 消息区底部 **64px**：线性渐变遮罩（透明 → `--bg`）+ `backdrop-filter: blur()` **由 8px 渐变到 0**；文字滚入该带逐渐模糊、淡出；输入区本身背景透明。
- **下边界严格贴住 composer 上边界**：零间隙、零越界；作为消息滚动容器的绝对定位子层，`bottom: 0`，**容器本身以 composer 顶边为底，不允许用固定高度另算**。
- 越界部分**一律隐藏**：所在容器 `overflow: hidden`；blur 作用范围不得延伸到输入区或窗口边缘之外；如需遮挡则把输入区背景置于模糊带之上（z-index 更高）。
- 允许近似：纯 blur 难逐像素渐变时可用「分段 blur 强度」或分段遮罩，视觉目标一致：**无线、无缝、文字渐隐入模糊**。
- 适用对话态、状态全景各演示块、响应式演示区**全部**对话实例；任意缩放 / 字号 / 主题切换后边界仍贴合。

### 5.6 滚动条（§9.4 + §9.10，全局所有可滚动容器）
- 宽 **4px**；轨道**全透明**；thumb 用 `rgba(border-strong)` 半透明 ⚠️（alpha 未规定）；hover 加深但**总宽不超 8px**；浅色近白融合、深色近黑融合；**禁止高对比突兀滚动条**。
- 显隐：滚动进行中**显示**；停止滚动 **1s 后开始渐隐**，渐隐过渡 **1s**（scroll → 显示并重置计时器 → 1000ms 无滚动 → opacity 以 1000ms 过渡至 0）；悬停滚动条命中区或持续滚动时保持显示。
- 适用：消息区、下拉列表、设置内容区、历史侧栏。

### 5.7 焦点与动效
- 焦点自动落输入框（初始态）；焦点环仅 `:focus-visible`（2px `--accent`、offset 2px）。
- 视图切换：容器间 **180ms 淡入 + 4px 上移**，不整页跳变；初始态 → 对话态用 **160ms 展开动画**；浮层 **160ms `scale(0.96→1)` + fade** 弹入；Toast 底部上浮 8px；主题切换 200ms。
- `prefers-reduced-motion: reduce`：**全部动画降为 opacity 淡入或直接切换，不做位移缩放**。
- 性能：**仅用 transform/opacity 驱动**，禁用触发重排的属性动画；动效不得造成**任何布局跳动**。

## 8. 硬约束与「禁止」清单

**产品级硬约束**：明暗**双主题**；窗口可缩放 **320–900+px**；字号可放大至 **125% / 150%**；**WCAG 2.2 AA**；核心路径「呼出 → 输入 → 发送 → 读流式回复 → Esc/关闭离开」**≤ 3 秒上手**；焦点自动落输入框；动效不得造成布局跳动。

**明确避免（用户点名，§0）**：SaaS 仪表盘感、大面积渐变、玻璃拟态、卡片堆叠、巨大标题、网页导航栏、营销落地页风、过度圆角、装饰性图标、固定尺寸布局。

**风格 → 参数**（§0）
- 轻量/克制 → **单一强调色（鲸蓝）、无渐变、无玻璃拟态、阴影极少（仅浮层有）**。
- 原生桌面感 → Segoe UI、紧凑控件（**28–32px 高**）、细边框（**1px**）、系统级焦点环。
- 紧凑但不拥挤 → **4px 间距栅格**、消息区 **16px 内边距**、行高 **1.55**。
- 清晰层级 → **只用「色彩明度 + 字重」表达，不用阴影堆叠**。
- 低干扰 → 弹出动画 **≤160ms**、无边框装饰、无营销元素。

**§10 颜色硬规则（全局强制）**
- 全站配色**只允许引用 CSS 自定义属性**；**禁止任何写死的白色/浅灰文字色**：`#FFF`、`#FFFFFF`、`#ECEEF1`、`#E8EAED`、`rgba(255,255,255,…)` 一律**不得出现在元素样式中**。
- **纯白仅允许作为 `--on-accent`**，出现在蓝色主按钮 / 用户气泡内。
- 确需固定色值时必须**在该元素上显式锁定深色背景**——「**浅字永远绑深底**」。
- 目标：浅色主题所有文字白底对比 **≥4.5:1**；深色主题暗底同样达标。基准：`--text-secondary` 白底 **≥5.4:1**；暗色 `--accent-fill` + 白字 **≥4.6:1**。
- 修复覆盖面：AI 正文、代码块文字、chip/下拉/按钮文字、消息 hover 操作键、设置表单、历史侧栏、状态全景各演示块、自定义 Provider / 获取模型列表 / 历史抽屉等 v1.1 新增区。

**可访问性**：焦点环 `2px solid --accent` + `outline-offset: 2px`，**仅 `:focus-visible`**；窄窗下**全部触摸目标 ≥24px** ⚠️（与刻度 hover 命中区 12px 宽有张力，A11）；`prefers-reduced-motion: reduce` 降为淡入/直切；ARIA 细节**未规定**（仅要求 WCAG 2.2 AA）。

**「不要发明」类**
- `--fs-display`（20px）**仅设计系统页**使用，产品界面内**禁用巨大标题**。
- 卡片一律 **1px 边框 + `--shadow-card: none`**；阴影仅浮层（`--shadow-pop`）与网页展示窗口框（`--shadow-window`）。
- 流式中**不做大面积遮罩**；消息区与输入区之间**无分隔线**。
- 长名称**不得省略/截断**：下拉中的**模型名称与角色预设不省略、不截断**，列表项宽度按最长名称自适应，需要时**自动换行多行完整显示**，320px 最小窗口下也能完整显示全部条目（§9.4）——**废止 §2.4「max-width 200px + ellipsis + tooltip」**。
- 下拉弹层**不得被窗口边界裁剪**：必须 fixed 浮层、允许越出窗口框（§9.5）。
- 全尺寸（320–900px）下**不允许任何按钮被裁剪或挤出可视区**（§9.5）：间距降档 12→8→4、图标按钮收缩至 24px、带文字按钮在 <400px 降为纯图标、输入宽度 100% 弹性。
- 不实现 Agent / 模型调用 / 凭据加密 / 会话持久化等逻辑（用户已声明不要求，§8）；对话内容为演示数据。
- 网页演示中的窗口阴影与 title bar 为模拟，真实产品由 OS 窗口管理器提供（§8）。
- 交付页（§7）工程要求：Token 全部 CSS custom properties；主题用 `[data-theme]` 切换；字号档位改根 `font-size`。

### §12 v1.4（2 条反馈；**覆盖 §11.1 中与之冲突的描述**）
- **12.1 刻度条**：默认长度**减半 16px → 8px**（2px 高、4px 圆角、间距 4px，hover 命中区 12px 不变）；**右端统一对齐同一右基线**（滚动条左侧 4px 间隙处）；当前刻度**向左凸出** 8px → **12px**（凸出 4px，右端贴基线）；切换 120ms 过渡；一问一刻度、点击平滑定位、流式最末高亮、避开滚动条不变。
- **12.2 全局过渡动画体系**：新增 `--dur-drawer: 240ms cubic-bezier(0.2, 0, 0, 1)`、`--dur-view: 180ms ease-out`、`--ease-smooth: cubic-bezier(0.2, 0, 0, 1)`；`--dur-fast` 复述为 120ms ease-out（hover/press/**刻度切换**）、`--dur-expand` 160ms。逐场景：

  2. 主内容区视图切换：180ms 淡入 + 4px 上移；初始态→对话态沿用 160ms 展开。
  3. 浮层（模型/角色下拉、确认框、Toast）：160ms `scale(0.96→1)` + fade；Toast 底部上浮 8px。
  4. 主题切换：颜色过渡 200ms，无闪烁。
  5. 状态全景各演示卡应用同一套动效。
  6. 无障碍：`prefers-reduced-motion: reduce` 下全部动画降为 opacity 淡入或直切，**不做位移缩放**。
  7. 性能：**仅 transform/opacity 驱动**，禁用触发重排的属性动画；**不得造成布局跳动**。
