快捷对话的联网搜索

搜索轮次上限每多一轮多消耗一次模型调用（宿主限制每分钟 8 次）
自定义搜索端点留空则用内置（先 DuckDuckGo，不通退 Bing）
填 https://api.tavily.com（只写域名也行，会自动补上 /search）—— Tavily 这类 API 只接受 POST，插件会按端点自动换成正确的请求方式； SearXNG 之类的 GET 端点照旧。留空就用内置搜索。
搜索 API Key可选
Key 以 Authorization: Bearer 发送（Tavily 的 key 形如 tvly-…）。 保存后可以先在「角色预设」里确认角色的「联网搜索」是打开的， 再问一个需要最新信息的问题看「处理过程」里那一行是否变成绿色。
